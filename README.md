# EduminD Contents

[🇮🇷 فارسی](README-FA.md)

Educational content, technical guides, and hands-on learning resources from **EduminD**, the educational initiative of **XminD**.

This repository contains the source materials, documentation, examples, and supporting resources created as part of the EduminD educational content ecosystem.

## 📚 Contents

The repository currently includes educational resources covering topics such as:

- **Home Lab** — Guides and documentation for building and working with a personal technical lab environment.
    
- **MQTT** — Educational materials covering MQTT concepts, messaging architecture, topics, payloads, and practical usage.
    

More topics and learning resources will be added over time.

## 📁 Repository Structure

```text
EduminD-Contents/
├── Home_Lab/
├── MQTT/
├── assets/
├── LICENSE
└── README.md
```

The repository structure evolves as new educational topics and resources are added.

## 🎯 About EduminD

**EduminD** is the educational initiative of **XminD**, focused on creating practical and technically accurate learning resources.

The goal is to explain technical concepts clearly while maintaining the depth and accuracy required for real-world use.
